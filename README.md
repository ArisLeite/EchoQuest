# 📜 EchoQuest ⚔️

> **Every Study Session is a New Quest.** <br>

[Live Demo](https://arisleite.github.io/EchoQuest/)

EchoQuest is a web application designed to help students organize their study routine, maintain focus and track their progress through a gamified experience inspired by RPG games. <br>
The project is currently **under development**.

## About the Project:

The idea behind EchoQuest is to transform studying into an interactive journey.

Instead of treating study activities simply as tasks, the application uses concepts inspired by RPGs:

* Tasks → Quests
* Study schedule → Journey
* Progress → XP
* Achievements → Rewards
* Study sessions → Focus Missions

## Design:

The interface combines a modern web design with visual elements inspired by RPG and videogame interfaces. <br>
The goal is to create an experience that feels less like a traditional productivity application and more like a personal study adventure.

## How to Run the Project:

Clone the repository:

```bash
git clone https://github.com/ArisLeite/EchoQuest.git
```

Open the project folder and launch the main HTML file in your browser.

The project is currently being developed and new features are being implemented continuously.
